# hotel-booking-app（ホテル予約アプリ）

イベント会場の住所をピンポイントで指定したり、旅先を少し広いエリアで指定してホテルを検索できるアプリです。
目的地からの徒歩時間／徒歩＋公共交通機関での所要時間、シャワー・バスタブ・大浴場などの設備、予算などで絞り込みができます。

## ⚠️ clone しただけでは動きません

このリポジトリは Muse の「スペース」のソースコードのミラーです。
動かすには、リポジトリに含まれていない **SDK・DB・画像・ランタイムサービス** の補完が必要です。

**まず [GUIDE.md](GUIDE.md) を読んでください。** 不足しているものの一覧と、復元／移植の手順をまとめています。

要点だけ：

- `@hatch/space-sdk` は Muse 環境内のローカルファイルを指すため、外では `bun install` が失敗します
- DB（`app.db`）は含まれていません。`drizzle/` のマイグレーションから空で再作成できます
- ヒーロー画像 `client/src/assets/hotel-hero.webp` は含まれていません（バイナリのため）
- ホテル検索はランタイム提供の Web 検索／推論（`ctx.*`）に依存しています

## 構成

- `client/` — React クライアント（UI、地図、お気に入り・履歴・宿泊メモの画面）
- `server/src/actions.ts` — サーバーアクション（ホテル検索、お気に入り、履歴、宿泊メモ）
- `server/src/schema.ts` / `drizzle/` — SQLite スキーマとマイグレーション
- `DATA-PLAN.md` — データ取得方針と情報源の詳細
- `GUIDE.md` — セットアップガイド
